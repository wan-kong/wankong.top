## HeadLess

Html的组件库进化经历了很多阶段，从Bootstrap+jQuery的组合，到 node+npm 的 包和构建，然后衍生出了 ElementUI/ AntDesign 等流行的组件库。
再到近年的TailwindCss的原子化设计，shadcn/UI 的设计理念一统江湖。

组件库的迭代实际上是跟随着CSS方案的迭代进行的（class方案->bfc方案->原子化css）。

在社交平台上看到了很多优秀的组件库，所以留个位置记录一下备忘录。


- [shadcn/ui](https://ui.shadcn.com/) : 万物之源
- [MagicUI](https://magicui.design/) : 包含用于创建着陆页和面向用户的营销材料的组件、模块和模板
- [AnimateUI](https://animate-ui.com/) : 给shadcn/ui 加上动画
- [ReactBits](https://reactbits.dev/) : 提供灵活、视觉效果惊艳且最重要的是免费的组件
- [Cult UI](https://www.cult-ui.com/) : 一套精心挑选的、小众的、动画组件，旨在与 shadcn 主题变量、模式和工作流程配合使用
- [Aceternity UI](https://ui.aceternity.com/) : 采用 Tailwind CSS 和 Motion 构建。兼容 Shadcn，并包含微交互和动画效果
- [Spectrum UI](https://ui.spectrumhq.in/docs) : 适用于 SaaS 仪表板、着陆页、AI 应用程序和管理面板。
- [Hero UI](https://heroui.com/) : HeroUI 是面向网页与移动端的现代 UI 库，有助于你快速迭代、保持一致，并打造令人愉悦的用户体验。
- [BeUI](https://beui.dev/) : 使用 Motion 和 Tailwind CSS 构建的免费开源 React 动画组件。
